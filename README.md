# medtrack

Medication reminder app for a handful of people. Android app first (Expo), website later, iOS maybe.

| Part | Where | Status |
|---|---|---|
| API (FastAPI, Python 3.12) | `backend/` | Phase 0 — walking skeleton |
| Android/iOS app (Expo) | `apps/mobile/` | not started |
| Web app (React + Vite) | `apps/web/` | later |
| Generated API types | `packages/api-types/` | later |

The full architecture and phase plan lives in [`docs/plan.md`](docs/plan.md); one-paragraph records of the decisions in [`docs/decisions.md`](docs/decisions.md).
